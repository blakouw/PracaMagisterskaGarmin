# 19 Packaging Windows Visualization

This helper previews the latest Windows packaging artifacts. It does not build the package, start the packaged runtime, run the analytical pipeline, call Garmin APIs or call LLMs.

Run:

```bat
visualization\19_packaging_windows\run_visualization.bat
```

Show packaged file hashes:

```bat
visualization\19_packaging_windows\run_visualization.bat --show-files
```
