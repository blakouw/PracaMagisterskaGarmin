# 16 Persist Local Snapshot Visualization

Text preview for published dashboard snapshots. It reads snapshot publication artifacts and the current snapshot metadata only. It does not start API/UI, call LLM, or print private payload contents.

Run:

```bat
visualization\16_persist_local_snapshot\run_visualization.bat
```

Optional flags:

- `--show-current`
- `--show-history --limit 10`
- `--show-hashes`
- `--show-status`
- `--show-manifest`
