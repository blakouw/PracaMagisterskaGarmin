# Local Dashboard UI Contract Preview

This helper previews UI contract artifacts generated by `pipeline/18_angular_dashboard_ui/build.bat` or `validate_ui_contract.py`.

It does not start the frontend, start the API, run the pipeline, perform network requests or call an LLM.

Run:

```bat
visualization\18_angular_dashboard_ui\run_visualization.bat
```

Optional flags:

- `--show-components`
- `--show-runtime`
- `--show-validation`
- `--show-lineage`
