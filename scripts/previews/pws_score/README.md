# Preview Deterministic PWS

This debug helper previews module 12 deterministic PWS artifacts. Records may contain private derived health and training information.

Run:

```bat
visualization\12_compute_pws_score\run_visualization.bat
```

Options:

- `--show-records --limit 10`
- `--show-date YYYY-MM-DD`
- `--show-contributions`
- `--show-coverage`
- `--show-chart-data`
