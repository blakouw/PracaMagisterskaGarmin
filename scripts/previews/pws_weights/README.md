# Preview PWS Weights

This debug helper prints a concise summary of module 11 artifacts. The records may contain private derived health and training information.

Run:

```bat
visualization\11_compute_pws_weights\run_visualization.bat
```

Options:

- `--show-records --limit 10`
- `--show-date YYYY-MM-DD`
- `--show-base-weights`
- `--show-effective-weights`
- `--show-guardrails`
- `--show-overlaps`
