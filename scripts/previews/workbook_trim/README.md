# 03 Trim Workbook Preview

This preview prints the KEEP/DROP decisions and artifact paths generated by module 03. It does not show full private records by default.

Run module 03 first:

```bat
pipeline\03_trim_workbook\run.bat
```

Then run:

```bat
visualization\03_trim_workbook\run_visualization.bat
```

Optional local debugging can show up to five rows from one trimmed CSV:

```bat
python visualization\03_trim_workbook\preview_trim_report.py --show-sheet Daily_Summary --limit 5
```

Rows displayed by `--show-sheet` may contain private Garmin health and activity data.
