# 02 Read XLSX Workbook Preview

This preview prints workbook structure generated by module 02 without showing full private records by default.

Run module 02 first:

```bat
pipeline\02_read_xlsx_workbook\run.bat
```

Then run:

```bat
visualization\02_read_xlsx_workbook\run_visualization.bat
```

Optional local debugging can show up to five rows from one raw sheet:

```bat
python visualization\02_read_xlsx_workbook\preview_workbook_structure.py --show-sheet Sheet1 --limit 5
```

Rows displayed by `--show-sheet` may contain private Garmin health and activity data.
