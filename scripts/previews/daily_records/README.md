# Module 05 Visualization

Preview normalized daily records, schema and quality coverage without printing private records by default.

Run:

```bat
visualization\05_normalize_daily_records\run_visualization.bat
```

Optional local debug:

```bat
python visualization\05_normalize_daily_records\preview_daily_records.py --show-records --limit 5
```

The optional record preview may display private health and activity data.
