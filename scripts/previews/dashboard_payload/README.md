# Visualization for 15_build_dashboard_payload

Reads `dashboard_payload.json`, `dashboard_payload_quality_report.json` and `dashboard_payload_schema.json` and prints a concise local debug summary. It does not run the production module, does not start an API or UI, and does not call an LLM.

Run:

```bat
visualization\15_build_dashboard_payload\run_visualization.bat
```
